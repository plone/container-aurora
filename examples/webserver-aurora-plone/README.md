# Setup with Webserver (Nginx), Frontend (Aurora), and Plone Backend

## Intro

Clone this repository and go to the `examples/webserver-aurora-plone` folder

```shell
git clone https://github.com/plone/plone-aurora.git
cd plone-aurora/examples/webserver-aurora-plone
```

Start the solution with `docker-compose` (or `docker compose` for newer versions)

```shell
docker-compose up -d
```

## Access the site

After startup, go to `http://localhost/` and you should see the site.
